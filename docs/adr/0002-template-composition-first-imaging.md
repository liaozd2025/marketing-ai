# ADR-0002: 配图以模板合成为主、AI 生图为辅，效果类图强制实拍

日期：2026-07-29 · 状态：已接受

## 背景

Phase 1 四个 Skill 含小红书图文，配图链路进入 MVP。首发垂类是美业/大健康：AI 生成「效果图」（皮肤改善、体型变化等）触碰广告法虚假宣传红线，且微信/小红书平台严打。纯 AI 生图还有中文文字渲染不稳、品牌视觉不一致的问题。

## 决策

- **主路线：模板合成**——HTML 模板（复用前端组件体系）+ 品牌视觉 + 商家实拍素材 + 文案，headless 渲染成图。
- **辅路线：AI 生图**——仅用于氛围图、装饰元素等不涉及效果承诺的图。
- **硬约束：效果类图一律使用素材库实拍照片**，生成链路禁止用 AI 产出效果类图。

## 后果

- 需要一个 HTML→图片的渲染服务和一套卡片/封面模板库。
- 素材库（实拍照片+打标）成为配图质量的上游依赖，地位很重。
- AI 生图 provider 也走多模型抽象层，但不在关键路径上。
