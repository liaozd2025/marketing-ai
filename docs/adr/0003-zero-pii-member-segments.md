# ADR-0003: 会员触达走分层模板模式，平台零 PII

日期：2026-07-29 · 状态：已接受

## 背景

会员生命周期触达 Skill 可以做成 CRM 模式（导入真实会员记录，按人生成个性化触达），但那会让平台从第一天承担《个人信息保护法》合规义务（加密、授权、删除权），安全等级和开发量完全不同。

## 决策

知识库只存**会员分层定义**（如新客、活跃、沉睡、卡项将到期）及各分层的触达场景；Skill 按分层生成话术模板，商家自行发送给对应的人。平台不存储任何可识别个人的信息。

## 后果

- 数据模型中不出现会员个体记录；实体命名用「会员分层（Member Segment）」而非「会员」。
- 个性化靠话术模板中的占位表达由商家发送时自行补充。
- CRM 化（若做）是未来独立的大决策，需重开 ADR，并伴随合规建设。
